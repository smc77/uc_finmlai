# Homework Sequence

The seven assignments accumulate a **research workflow**, not one compulsory dataset:

| Assignment | Data relationship | Evidence rule |
|---|---|---|
| HW1 | Student-chosen univariate market series | Build and audit the initial pipeline |
| HW2 | Reuse or adopt the corrected HW1 pipeline | Spend one declared HW2 assessment block |
| HW3 | Extend the series with a new forward window | Do not relabel the spent HW2 block as test data |
| HW4 | New multi-asset panel | Descriptive structure; do not force a market-factor conclusion |
| HW5 | Reuse the HW4 panel or use the supplied known-truth panel | Evaluate portfolio decisions and costs |
| HW6 | Student's final-project data | Use development evidence and preserve a final lockbox |
| HW7 | New financial-text corpus | Transfer the workflow to a different data modality |

Assignments are released on the schedule in the syllabus. Each released folder
contains a starter notebook and a README explaining what to do and submit. A
reference solution is posted after the deadline so that an early mistake does
not have to carry into later work.

## Submission

Every assignment is submitted the same way: **one executed notebook** uploaded to the
Canvas assignment, named `hwN_lastname.ipynb`. Run **Restart & Run All** first, confirm
the self-check prints PASS, and save with outputs visible — the outputs are part of what
is graded. Submit the `.ipynb` file rather than a PDF, an HTML export, or a link to a
Colab or Drive copy, since a shared link can change after the deadline.

## Self-checks

Self-checks cover mechanical invariants such as date ordering, target completeness, future
invariance, fold-local preprocessing, position/return alignment, and metric availability. They
cannot certify economic judgment, data provenance, or every form of leakage. A passing self-check
is necessary but not sufficient for full credit.

## Written responses

Written answers are graded on **accuracy, completeness, clarity, and relevance**, not on word
count. Any suggested length or paragraph structure is guidance intended to help students give
each part adequate attention; it is not an independent grading criterion. A concise complete
answer and a longer complete answer can both earn full credit. Missing analysis, unsupported
claims, and irrelevant material may still reduce the score.

## Optional extensions and bonus

Required work earns full assignment credit. Extensions are genuinely additional and should be
attempted only after the core passes. The assignment in Canvas identifies the extension's bonus
value; homework and final-project extensions together can add at most three percentage points to
the course grade, as stated in the syllabus.
