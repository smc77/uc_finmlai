# Literature and source map

This map records what each source changes in the research design. It is not a
list of papers added after the result.

| Source | Design consequence |
|---|---|
| SEC Form 8-K and instructions | Defines the current-report container and distinguishes Item 2.02 from Item 9.01 and its exhibits. |
| Apple filing detail, accession 0000320193-23-000005 | Supplies the exact acceptance clock, item labels, accession, and Exhibit 99.1 link used in the classroom walkthrough. |
| Apple Exhibit 99.1 | Shows the actual source document converted to text and scored by both readers. |
| Loughran and McDonald (2011) | Motivates a transparent finance-domain word-list baseline rather than a generic sentiment dictionary. |
| Araci (2019) | Identifies FinBERT as the contextual sentiment candidate; it does not establish that sentiment predicts future revenue growth. |

The empirical question remains downstream of the text-classification literature:
does the pinned candidate add useful ranking information relative to the baseline
on a later, point-in-time test?
