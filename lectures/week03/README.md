# Week 3 — Linear Models, Shrinkage, and Forecast Evaluation

Use these files alongside the Week 3 recordings and slides in Canvas:

- [`week3_demos.ipynb`](week3_demos.ipynb) — six demonstrations for the
  lecture breaks, plus an optional real-data comparison after Demo 1;
- [`week3_summary.md`](week3_summary.md) — a plain-English review of the core
  ideas, vocabulary, common mistakes, and study checks; and
- [`reading.md`](reading.md) — aligned textbook chapters and optional public
  background readings.

At each lecture break, use the notebook index to open the named demonstration.
Run the code, complete the editable research-record entry, and only then open
the collapsed completed entry beneath it. The completed entry uses exactly the
same fields, in the same order, so you can compare the specificity of your
answer without treating its wording as a template to memorize.

The six entries are practice in keeping a research record. They remain in this
notebook and are not separate submissions. The final-project research record
begins later in the semester.

The lecture, notebook, and summary are sufficient for the course work. Further
readings are optional unless Canvas says otherwise.
