# Week 0 — GitHub, Coding Agents, and Colab/Python

Week 0 is one ungraded 60-minute orientation. Repository access and a working
notebook are expected. Claude Code or Codex is optional.

## Accompanying textbook chapters

- None. Week 0 is a practical setup and orientation session. The textbook
  begins with the financial-machine-learning ideas introduced in Week 1.

## Before the lecture

- Sign in to GitHub and open <https://github.com/smc77/uc_finmlai>.
- Click **"Use this template"** to create your own repository, and set its
  visibility to **Private**. You commit and push your work there; add the course
  repository as an `upstream` remote to pull each week's material. At the end of
  the course you can flip it to public as your portfolio.
- Open `lectures/week00/setup.ipynb`.
- Decide whether Colab or local Python will be your first notebook route.

## Readiness evidence

Keep these for yourself:

1. your own repository, its `origin` remote, and a successful push;
2. one clean top-to-bottom run of the setup notebook;
3. the Python executable path and package versions;
4. if using an agent, one prompt and inspected diff.
