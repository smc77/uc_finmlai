# Week 2 — Features, Targets, and Point-in-Time Data

Use these files alongside the Week 2 recordings and slides in Canvas:

- [`week2_demos.ipynb`](week2_demos.ipynb) — the demonstrations and
  mini-projects for both lecture parts, with links at the top that jump directly
  to every demo;
- [`week2_summary.md`](week2_summary.md) — a concise review of the core ideas,
  vocabulary, and Quiz 2 study checks;
- [`reading.md`](reading.md) — the aligned textbook chapters, optional exercises,
  and supplementary reading route.

The notebook is self-contained: its real GDP vintage example includes a compact
offline extract, so it works in Colab without an API key or a separate data
download. At each lecture break, use the notebook's index to open the named demo;
you do not need to rerun all earlier cells unless the demo depends on their
shared setup.

The lecture and notebook are sufficient for the course work. The further
readings provide additional background and are optional unless Canvas says
otherwise.
